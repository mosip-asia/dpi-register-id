# C3 — Stdout logs, Redis required, no log files

## Previous

Application logging opened files under `LOG_DIR`. Audit, locks, staff, and activity grants wrote JSON on disk when `REDIS_URL` was empty. Startup planted `LOG_DIR`, `LOG_NAME`, and `LOG_ROTATE_NAME` defaults.

## Expected

Production logs are stdout only. `REDIS_URL` is required. No log files.

## Now

`logger.py` attaches only a stdout stream handler. The `LOG_*` path defaults are gone. Audit, locks, staff, and activity grants use Redis when `REDIS_URL` is set. When it is empty they raise and do not create a directory or a file. `AUDIT_BACKEND=file` and `FILE_STORE=1` are test opt-ins. A configured Redis that is down raises and does not fall back to a file. Redis wins when both the URL and the opt-in are set.

## What was done

File handlers were removed from the logger. Each store's `_open_store` follows the audit rule. Tests that need a directory set the opt-in. The working-tree note that described an automatic audit file was updated.
