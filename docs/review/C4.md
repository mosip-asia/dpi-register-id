# C4 — Production image runs as uid 1000

## Previous

The production runner stage already ended with a numeric user. The development stage still used `USER $USERNAME`, which Kubernetes `runAsNonRoot` cannot check by name.

## Expected

The image CI pushes runs as numeric uid/gid 1000.

## Now

The runner stage creates uid/gid 1000 and its last `USER` instruction is `USER 1000:1000`. `EXPOSE`, `HEALTHCHECK`, and `CMD` follow that instruction. The development stage is not the image that is pushed.

## What was done

The runner `USER` line was confirmed and left numeric. The A1 mock deletion was inserted before that `USER` line so the production user did not change.
