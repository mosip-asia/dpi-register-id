# A8 — Keycloak username is the UIN

## Previous

The Keycloak username was the email local-part. `john@a.edu` and `john@b.edu` became the same user.

## Expected

The username is derived from the UIN.

## Now

`provision_citizen` sets `username = uin` and looks users up by that username. The email is a separate attribute. Tests create `ada@example.com` with UIN `1234567890` and expect the username to be the UIN, not `ada`.

## What was done

The `email.split("@")` derivation was removed from `keycloak.py`. The create payload, the 409 lookup, and the tests were updated to the UIN.
