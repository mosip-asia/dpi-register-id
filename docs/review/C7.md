# C7 — Generic SMTP, optional login, mail does not fail enrolment

## Previous

Mail used a Gmail shortcut and an app password. `_deliver` always called `starttls` and `login`. Compose did not pass a generic host. A mail failure already did not fail enrolment.

## Expected

Generic SMTP host, port, and optional STARTTLS. Credentials optional. A delivery failure must not fail enrolment.

## Now

`SMTP_HOST` and `SMTP_PORT` win over `EMAIL_PROVIDER=gmail`. `SMTP_STARTTLS` defaults on, and `0`, `false`, `no`, or `off` skip STARTTLS. `login` runs only when `EMAIL_PASSWORD` or `SMTP_PASSWORD` is set. `send_enrollment_email` catches SMTP errors and returns `emailSent: false`. Enrol has already written IDRepo by then. Compose passes `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, and `SMTP_STARTTLS`. The Gmail shortcut remains.

## What was done

`_smtp_target` and `_deliver` learned the generic host and the two optional steps. Email tests cover a send with no login and a send with STARTTLS off. `.env.example` lists the SMTP variables.
